2. 日常操作：採集 → 整理 → 歸檔

A. 現場採集（不用中斷手上的事）

首頁四顆大按鈕，按了就開始：

  • 🎥 錄影／📷 拍照／🎙 錄音／✏️ 記事
  • 錄音每 10 分鐘自動分段上傳，斷網會先存在手機、有訊號再補傳
  • 錄音中拍的照片會自動標記「錄音第幾分幾秒拍的」，事後對得回逐字稿
  • 採集的東西先進收件匣，不用當場分類
現場專心看展、做實驗就好。先採集，事後整理——這是這個 App 唯一的設計原則。

B. 一鍵整理（把聲音和圖變成文字）

有空時打開那筆紀錄，按 🪄 Cloudflare AI 整理：

  • 會把「還沒轉文字的錄音」全部轉、「還沒擷取文字的照片」全部擷取
  • 已經處理過的不會重跑，不浪費額度
  • 按鈕旁顯示「⏳ N 筆待整理」；顯示「✓ 已全部整理」而且反灰時，代表沒事可做，不用按
  • docx／xlsx／pptx／txt／csv 這類檔案不經過 AI，後端直接解出文字，不扣額度

C. 歸檔

打開收件匣裡的紀錄，選「歸檔到」某個資料夾；也可以當場「＋ 建立新資料夾並歸檔」。

D. 匯出給 AI 寫報告

資料夾右上角 📄 匯出給 AI → 產出一份 Markdown 原料包 （含所有逐字稿、擷取文字、欄位）→ 貼給 Claude 說「彙整成報告」→ 存進 Notion。

Notion 自動同步還沒做完（欄位有了但沒接通），目前這一步是人工貼上。

E. 記一句

紀錄詳情裡可以一句一句往下加，每句獨立寫入、不會互相蓋掉，適合邊聽邊記重點。

3. 檔案與文字擷取

上傳

資料夾工具列 ＋ 上傳檔案 可一次選多個檔， 每個檔自成一筆紀錄（標題＝去掉副檔名的檔名）。同一個資料夾裡內容完全相同的檔案會自動去重。

🔬 深度處理（圖形型 PDF 專用）

有些 PDF 是圖檔排版、沒有文字層（例如廠商用 Illustrator 做的型錄）， 一般整理抽不到本文。這時用深度處理：瀏覽器把 PDF 逐頁轉成圖片，再走照片 OCR。

這個只能手動一份一份指定，刻意不做背景批次——很吃 AI 額度。

🏷 整理檔名

把標準文件的檔名統一成 組織_編號_年份_中文標題（例 ISO_10555-8_2024_體外血液處理用導管.pdf），並移除內容完全相同的重複檔。 不會呼叫 AI，用既有的 OCR 與檔名資訊推。年份推不出來時不會硬猜， 會保持原檔名不動。

醫材分類

單一檔案可以掛醫材分類（CVC／HD／Pigtail／高壓注射筒組…），選項來自分類字典。 打錯字不會產生幽靈分類——存檔時會驗證。

🔗 關聯

兩筆記事之間可以建立關聯，例如「這次實驗引用了這份 ISO 標準」「這家廠商對照這篇專利」。 關聯是雙向的，而且必須手動建立過才查得到——系統不會自己猜。

🔍 這筆資料的來歷

每一筆記事詳情往下滑到底，有一段「這筆資料的來歷」，回答四個問題：

  • 這筆哪來的：現場採集／外部知識庫同步（含來源代號）／從 Medtec 匯入／ 透過 claude.ai 新增。如果原始資料已經從來源移除，這裡會警示
  • 誰在何時改過：完整的操作履歷，只增不刪
  • AI 動過哪些地方：每個附件的轉文字／擷取文字／深度解析狀態。 「已判定不需處理」代表跑過但沒有可擷取的內容（例如照片裡就是沒有字）， 不是漏掉——所以不會被重複扣費
  • 原始資料列（可展開）：Cloudflare D1 實際存的欄位長什麼樣。 超長的文字只顯示開頭並標明總長度
專利與法規場景需要的是「誰在何時記錄了什麼、依據什麼」的可稽核紀錄。 這一段就是為此存在——資料的來歷本身也是資料。

4. 資料夾架構與分類

四層架構

層級放什麼例子
第 1 層產品／專案中央靜脈導管（CVC）、血液透析導管（HD）
第 2 層文件類型法規與標準、驗證與確效、風險管理
第 3 層主題／試驗標準系列、試驗項目、國家／市場
第 4 層年份／版本年份／版本、單一標準文件、送件版本

最多四層，想建第五層會被擋下來。

⚙️ 管理分類

首頁「已歸檔資料夾」旁邊。分類存在資料庫裡，在這裡改完立刻生效， 不用改程式、不用重新部署。

  • 改名：既有資料夾上的分類文字會一起更新（同一個分類換叫法）
  • 刪除：只拿掉選項，既有資料上的分類文字保留不動，並告訴你還有幾筆在用

5. 外部知識庫自動同步

隨身記可以每天自動去外部的公開 JSON 抓資料進來（目前設定了 litdb 的三個收藏）。 台灣時間每天凌晨 02:00 自動跑，你不用做任何事。

它是怎麼運作的

  • 內容沒變就完全不動（比對內容指紋），只有真的改過的才更新
  • 你自己加的註記永遠不會被蓋掉：同步只改寫記事裡被 <!-- sync:start --> 與 <!-- sync:end --> 框住的那一段，你在這之後寫的東西不會被動到
  • 來源端刪掉的資料不會跟著刪，只會標記起來，要不要刪由你決定
  • 來源的專利分析內容（配方、FTO 風險、迴避設計）會存進「AI 深度解析」欄位， 搜尋查得到，而且看的時候會明確標示那是 AI 產出、不是你現場記的

要加一個新的知識庫

不用改程式碼，往來源清單加一列就好。三個關鍵欄位：

欄位意思
url公開 JSON 的網址
items_path資料陣列在 JSON 裡叫什麼（papers／reports／items…）
id_field每筆資料的唯一鍵欄位名（id／code…）
curl -X POST "https://fieldlog.gogoyankee.workers.dev/api/sources" \
  -H "x-pin: 你的FIELD_PIN" -H "content-type: application/json" \
  -d '{"key":"market","label":"市場分析",
       "url":"https://.../reports.json",
       "items_path":"reports","id_field":"code",
       "folder_parent":"LitDB 文獻庫"}'

想立刻同步、不等半夜

curl -X POST "https://fieldlog.gogoyankee.workers.dev/api/admin/sync-sources" \
  -H "x-pin: 你的FIELD_PIN"

一次跑完全部來源，不用自己翻頁。加 ?source=coating 可以只跑其中一個。

想知道「資料是不是過時了」，直接在 claude.ai 對話裡問，它會用 sync_status 工具告訴你每個來源最後同步的時間和筆數——不用靠記憶。

6. 用 claude.ai 問問題（MCP）

在 claude.ai 設定好 MyWiki 連接器之後，直接用講話的方式問就好， 它會自己決定要查哪裡。例如：

  • 「幫我查展商裡做親水塗層的」
  • 「上次實驗紀錄裡提到的固化溫度是多少」
  • 「litdb 裡有沒有講活檢針擊發機構的文獻」
  • 「wiki 的抗結痂條目現在寫到哪」
  • 「把 7/29 那筆 POM 膠測試的照片給我看」

四個讓查詢變準的技巧

① 查不到 ≠ 沒有這筆資料

最常見的失敗不是資料不存在，是關鍵字沒猜對。 叫它「先列出那個資料夾底下有什麼」，看檔名通常就知道要不要細看， 比反覆猜關鍵字有效得多。

② 內部代號查不到就當場補

公司內部代號、料號、慣用語（例如「BaClear」對應「抗結痂披膜」）只有你知道。 查不到的時候直接說「把 BaClear 加到抗結痂披膜的同義詞」， 它會用 add_synonym 補進去，下一次查詢立刻生效，不用改程式。

③ 照片可以直接叫它看，不是只能讀擷取出來的文字

斷面、外觀不良、現場擺設這種文字描述不出來的東西，直接說 「把那筆的照片給我看」，它會用 get_fieldlog_image 把照片本身取回來看。 只讀擷取文字（ocr_text）會漏掉重點——照片上沒有字的時候，擷取文字本來就是空的。

④ 看到「AI 深度解析」要留意

標示「AI 深度解析」的段落是 AI 整理／推論出來的，不是你現場記的原始證據。 要拿去寫報告或做決策前，回頭看原始內容或來源連結確認一次。

MCP 能改資料嗎？

只能新增，不能修改或刪除。22 個工具裡只有四支會寫入：新增一筆記事、 上傳一份附件、建立一個關聯、補一組同義詞。程式碼裡沒有任何一行能改掉或刪掉既有資料—— 就算你在對話裡叫它刪，它也做不到。要改內容、刪東西，一律回這個 App 自己操作。

7. AI 額度與成本

  • 轉文字／OCR 用 Cloudflare Workers AI，每天約 10,000 Neurons 免費額度， 隨身記與參展系統共用同一份
  • 自動處理只會用到 70% 安全額度（7,000），留餘裕給你手動觸發
  • 月付費有軟上限 USD 4.5，達到就停，不會靜默扣費
  • 首頁「Cloudflare 用量」區塊可以看目前狀況
用量數字是 Cloudflare 那邊回報的，可能落後一到數天。 看到「今日」數字沒動不代表沒在跑。

8. 疑難排解

畫面好像是舊版的

首頁標題旁邊有版本號（例 v57）。如果伺服器上是更新的版本， 畫面會直接跳出橘色警告並提供「一鍵清除快取」——按它就會解除 service worker、清掉所有快取、重新載入。

沒跳警告就代表你載到的確實是最新版，問題在別的地方。

查詢說「查無資料」但你確定有

  1. 先確認關鍵字沒打錯字
  2. 拿掉資料夾範圍限制，改成全庫查
  3. 叫 AI 先「列出資料夾底下有什麼」，用看的比用猜的準
  4. 確定只是用詞沒對上 → 用 add_synonym 補一組

系統查不到的時候會誠實告訴你它試過哪些詞，不會只回一句「查無」—— 就是要讓你分得出「真的沒有」和「有但沒對上」。

litdb 的新內容沒出現

問 claude.ai「查一下同步狀態」（sync_status），看最後同步時間。 還沒跑就等當晚 02:00，或手動打第 5 節那條 curl。

PDF 上傳後沒有文字

可能是圖形型 PDF（沒有文字層）。用 🔬 深度處理 逐頁轉圖再 OCR。

連 MCP 失敗／工具叫不出來

  • 401：PIN 沒帶或帶錯，確認網址結尾是完整的 ?pin=...
  • 新工具沒出現：連接器快取了舊的工具清單，去 Settings → Connectors 關掉再開

9. 維運速查

改完程式碼怎麼上線

三個 Worker 都接 GitHub 自動部署——push 到分支就會自動重新部署， 不用手動觸發。到 Cloudflare Dashboard 對應 Worker 的 Deployments 看狀態。

不要用 Dashboard 的「Edit code」直接改線上程式碼。 那會產生一個「Manually deployed」版本蓋掉 git 部署，之後 git 推上去的東西可能不會生效， 而且很難察覺。

Secret 放哪裡

Worker需要的 Secret
fieldlogFIELD_PIN
medtec-2026TEAM_PIN（LINE 相關為選用）
medapi-mcpMCP_PIN、FIELD_PIN（與 fieldlog 同值）

都在該 Worker 的 Settings → Variables and Secrets。

排程

fieldlog 有一個 cron：0 18 * * *（UTC）＝台灣時間每天 02:00， 自動同步所有啟用中的外部來源。

目前還沒做的事

  • Notion 自動同步：欄位有了但沒接通，目前人工貼上
  • AI 深度解析引擎：欄位與呈現都好了，但「自動呼叫 Claude 分析新資料」 那一段決定先不做。之後要做的話前提已經定案：fieldlog 自持金鑰、一律用 Sonnet、 只解析新資料＋提供手動按鈕，不做全量回補
  • 文獻折進 Wiki 條目：目前 litdb 的內容查得到，但還沒有「讀完自動掛回 A/B 技術條目」的流程
